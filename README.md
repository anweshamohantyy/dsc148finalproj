# DSC 148 Final Project: Flight Delay Prediction

## By: Anwesha Mohanty and Akshitaa Balasai

**Overview:** In this project, we use different models to predict the average flight delay (in minutes) for U.S. airlines. We ultimately use a Random Forest model trained on 60,000 records of airline delay data from 2003–2025.


## Demo
 **Click the link to check out a demo of our project!**
 Select an airline, airport, month, and year of your choice, and the model will predict the average delay in minutes.
